# PDFCompressorPro

A fast, simple, and lightweight web-based PDF compression tool built using HTML, CSS, and JavaScript. PDFCompressorPro helps users reduce PDF file sizes directly in the browser with an easy-to-use interface.

## Features

* Compress PDF files quickly
* Edit PDFs : Merge PDFs, Extract Pages & Rotate PDF
* Compress images quickly
* Also can convert .pdf to .jgp and Images to PDF
* Clean and responsive user interface
* Lightweight and easy to use
* Client-side processing
* No software installation required
* Works directly in the browser
  

## Technologies Used

* HTML5
* CSS3
* JavaScript

```bash

```

2. Open the project folder.

3. Run `index.html` in your browser.
